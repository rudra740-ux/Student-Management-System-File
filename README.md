# Student Management System

A File-Based Persistent Student Management System developed using Core Java.

## Features

- Add Student
- View Students
- Search Student by ID
- Delete Student
- File-based data persistence

## Technologies Used

- Java
- Core Java
- ArrayList
- File Handling
- Exception Handling

## File Storage

Student data is stored in a `students.txt` file.

The data remains available even after restarting the program.

## Project Structure

- Student.java
- FileManager.java
- StudentManager.java
- Main.java

## How to Run

Run the `Main.java` file.
